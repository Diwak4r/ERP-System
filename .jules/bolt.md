## 2026-03-29 - [Optimized RBAC and Section Selection with Request-Level Caching]
**Learning:** Redundant database queries for user roles and section permissions can be significantly reduced by caching data on the `user` object and pre-evaluating querysets into lists within views. Caching group names in `user._group_names_cache` reduces RBAC checks from $N$ to 1 query per request. Pre-evaluating `_available_sections` into a list and using in-memory lookups (e.g., via `next()` with a generator) eliminates redundant `Section.objects.filter` and `exists()` calls across multiple view functions.
**Action:** Always cache frequently accessed, request-scoped data like user roles or authorized object lists on the user or request object. Use in-memory lookups from evaluated lists to replace redundant database filters when the dataset is small (e.g., list of sections for a user).
